# dwb - skim Donor Folder

This folder is a curated donor copy from `dwb player` for a future `dwb - skim` project.

It is not a finished app and has not been renamed or changed for skim behavior. The copied project still contains `dwb player` names, bundle IDs, target names, schemes, settings, docs, and public strings.

Before starting the future bootstrap/adoption pass, manually move this folder out of the `dwb-player` repository and use the moved folder as the new project root.

See `DONOR_MANIFEST.md` for the included paths, excluded paths, safety notes, and follow-up work.
